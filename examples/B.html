Зависимости NuGet

Стрелка A → B: пакету A нужен пакет B. На пределе глубины зависимости не раскрываются.

Graphviz DOT

digraph Dependencies {
  rankdir=LR;
  node [shape=box];
  "B@1.0.0";
  "B@1.0.0" -> "D@1.0.0";
  "D@1.0.0";
}

Картинка: автономный SVG-просмотр. Для раскладки Graphviz используйте .dot.
